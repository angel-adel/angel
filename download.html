    Библиотека Ádel

    Программа для Windows с полным собранием стихов (600+ произведений)

    ⬇️ Скачать (154 МБ)

    ✨ Что нового в версии 2.0:

    • Облачная синхронизация: произведения подгружаются напрямую из базы сайта.
    • Умный поиск: мгновенно находит нужное по названию.
    • Фильтры: сортировка по языкам (RU, ES, EN) и типам (стихи, проза, юмор).
    • Сборники: удобная навигация по повестям и рассказам.
    • Избранное: сохраняйте любимые строки, чтобы вернуться к ним позже.
    • Темы: светлая и уютная тёмная для чтения ночью.

    📋 Как установить:

    1. Скачай архив по кнопке выше.
    2. Распакуй его в любую удобную папку (например, на Рабочий стол).
    3. Запусти файл Adel_Book_Reader.exe.
    4. Если Windows покажет синее окно «SmartScreen», нажми «Подробнее», а затем «Выполнить в любом случае» (это нормально, так как программа не имеет платной цифровой подписи).
    📌 Программа не требует установки. Работает на Windows 7/8/10/11.
